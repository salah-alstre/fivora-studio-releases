# FIVORA Studio — Releases

This repository hosts **release binaries only** for FIVORA Studio (Windows).
It contains no source code.

**Status: no public release yet.** Nothing here is approved for download.
Windows builds are not Authenticode-signed at this stage.

Each approved release will contain:

- `FIVORA-Studio_<version>_x64-setup.exe` (installer)
- `FIVORA-Studio-<version>-portable.zip`
- `SHA256SUMS.txt`

Always verify the SHA-256 of a download against `SHA256SUMS.txt`.
